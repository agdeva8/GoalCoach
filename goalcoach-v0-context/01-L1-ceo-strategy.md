The 10x version of GoalCoach is the kernel that actually remembers and tells the truth:

- Continuity memory across visits
- Honest cards that name drift, not flatter
- Data export that proves the user owns their history
- A thinking indicator with persona, not a blank spinner

Founder is the first user. 5 outside users in 14 days for the cohort validation gate.

## Dream state delta (12-month view)

v1 ships: chat-first AI coach with multi-horizon plan, polish layers, founder-as-first-user validated at D30.

12-month target: the kernel becomes infrastructure — every feature added in v1.1+ composes with the existing architecture without re-architecting.

This plan moves toward that target by: (1) keeping slice architecture extractable so a failed v1 acceptance test doesn't waste 3-4 weeks of work, (2) choosing SQL-only inter-slice contracts so new tools follow the same shape, (3) keeping the AI as the orchestration surface (one place to upgrade).
